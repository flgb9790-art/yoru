# Состояние реализации

Ограничение пользователя: остановиться с запасом до 60% недельного лимита Codex. Последняя проверка 17 октября: 7%. Не расходовать платные кредиты и сбросы автоматически.

Railway: отдельный проект YORU, PostgreSQL и web. Сайт: https://web-production-6bc5ed.up.railway.app . Telegram-вход подтверждён пользователем, владельцу выдана роль admin. Почта и плеер отложены.

Этот этап: обновлены каталог/страница аниме, профиль и история, библиотека со статусами, оценки, роли и модерация; предпросмотр Shikimori в ручной форме, защита отдельных полей, повтор импорта, расписание GraphQL, ежедневное ограниченное обнаружение релизов. Подробности и ограничения в README.

11 интеграционных тестов проходят. Браузерная проверка desktop/mobile выполняется перед выпуском. Код не выдаёт обновления каталога за появление перевода. История начнёт автоматически заполняться только после интеграции плеера.

GitHub CLI в текущем процессе сообщает недействительную авторизацию. Коммиты сохраняются локально; публикация в GitHub пока не подтверждена. .env исключён из репозитория и образа.
