# Расписание эфиров и правила содержимого

Проверено 24.10.2026. Везде хранится один UTC-момент следующего оригинального эфира; карточка, расписание и таймер используют его. Для отображения — Europe/Minsk (МСК, UTC+3). Время локализации/озвучки не подменяет оригинальный эфир. Строки без часового пояса не интерпретируются как точное время.

Календарь Shikimori сверяется с nextAiringEpisode AniList по совпавшим ID MyAnimeList, названию и году. Источники: https://shikimori.io/api/calendar и https://docs.anilist.co/reference/object/media. При существенном расхождении времени или номера эпизода дата становится неподтвержденной: отсчета нет, тайтл остается в разделе «Без даты». Оба исходных значения сохраняются в metadata.airingConflict. При временной ошибке второго источника ранее обнаруженный конфликт не снимается. Синхронизация — при запуске worker и каждый час, отдельно от полного импорта. Ручная защита metadata/metadata.nextEpisode соблюдается.

Подтвержденное исключение: BLEACH, Shikimori60636. Официальное https://bleach-anime.com/onair/ и https://www.tv-tokyo.co.jp/broad_tvtokyo/program/detail/202610/27169_202610262400.html указывают26.10.2026 24:00 JST, то есть26.10.2026 18:00 МСК. Ограниченная по сроку поправка находится в airing-sync.js; после этого эфира она перестает задавать следующие даты. Следующие выпуски не вычисляются прибавлением недели.

Таймер показывает дни/часы/минуты/секунды и использует серверный момент времени, а не часовой пояс устройства. После окончания отсчета сообщает о наступлении времени по расписанию, не заявляя доступность озвучки.

Проверка базы без изменений:

    node --env-file-if-exists=.env scripts/refresh-airing.js

Применение дат:

    node --env-file-if-exists=.env scripts/refresh-airing.js --apply

Даты + удаление рекапов с архивированием через существующий removeAnime:

    node --env-file-if-exists=.env scripts/refresh-airing.js --apply --remove-recaps

Контент: запрещены клипы/music, PV, CM, явно обозначенные игровые ТВ-шоу и рекапы/пересказы/сборники-пересказы. Обычные TV-аниме, OVA/ONA, фильмы и сюжетные special/tv_special сохраняются. Проверка идет до дополнительных запросов карточки, в отборе кандидатов и перед сохранением, независимо от настроек формата. Существующие исключенные записи архивируются штатным механизмом, их Shikimori ID попадают в запрет повторного импорта.

При ручном применении скриптом дата получает временную защиту metadata.nextEpisode с флагом airingTemporaryProtection, чтобы ещё работающая старая версия импортера не вернула прежний календарь. Первый успешный sync новой версии снимает только эту временную защиту. Настоящие ручные блокировки без флага сохраняются.
