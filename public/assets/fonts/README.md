# Шрифты YORU.

Space Grotesk используется для логотипа, Manrope — для интерфейса. Файлы WOFF2 раздаются самим сайтом; внешние сервисы при просмотре страниц не вызываются.

Подключены переменные веса: Space Grotesk 300–700 и Manrope 200–800. Для Manrope включены латиница и кириллица, для Space Grotesk — латиница логотипа.

Оба семейства распространяются по SIL Open Font License 1.1. Полные лицензии: `Space-Grotesk-OFL.txt` и `Manrope-OFL.txt`. Источники и дата загрузки записаны в `font-sources.json`.
