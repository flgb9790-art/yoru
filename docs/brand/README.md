# Бренд YORU — кицунэ

Утверждённая пользователем симметричная SVG-перерисовка хранится в approved-kitsune.svg. Основной цветной знак в public/favicon.svg должен совпадать с ней визуально; это проверяется тестом сравнения пикселей.

Общий исходник геометрии: scripts/brand-geometry.js. Команда npm run build:brand создаёт SVG/PNG/ICO, Apple Touch Icon, обычные и maskable PWA-иконки и Android VectorDrawable из одних контуров. sharp нужен только при разработке и сборке иконок, в рабочем сервере он не используется.

- Favicon: SVG со скруглёнными углами, ICO 16/32/48 и соответствующие PNG. На 16 px убраны мелкие радужки глаз для читаемости.
- iOS: apple-touch-icon.png, 180 px, непрозрачный квадрат; углы обрезает сама система.
- PWA: 192/512 px и отдельные maskable 192/512; важные детали помещаются в безопасную область круглой маски.
- Android: адаптивный launcher, отдельный монохромный вариант и значок уведомлений; новый знак используется существующим анимированным экраном запуска. Release 0.1.7/versionCode8 подписан прежним ключом, приложение можно обновлять поверх версии 0.1.6.
- Сайт: в хедере только надпись YORU; знак обновлён в футере, превью плеера, разделе приложений и иллюстрациях установки. Офлайн-библиотека получает обновлённую надпись, не удаляя сохранённые серии.

Версия ресурсов — v5; кеш офлайн-оболочки — v7, префикс сохранённых видео оставлен прежним. Иконки уже установленных ярлыков могут кэшироваться системой; для iOS при необходимости повторно добавить сайт на экран «Домой». Новый знак Android появляется после установки обновлённого APK.

Проверено: 238/238 Node-тестов, Android assembleRelease/testDebugUnitTest/lintDebug, подпись APK, размеры/прозрачность иконок, safe zone maskable, браузер в двух темах на 320/390/760/1024/1440, загрузка офлайн-библиотеки без сети. Физическая установка на телефон не выполнялась.
