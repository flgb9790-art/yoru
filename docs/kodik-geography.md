# Региональная видимость Kodik

Страна определяется локально по `req.ip` (IPv4/IPv6), используя `geoip-country`/GeoLite2. Данные GeoLite2 созданы MaxMind: https://www.maxmind.com. База распространяется по CC BY-SA 4.0 с условиями GeoLite2 EULA; лицензии включены в npm-пакет. Версия базы фиксируется в package-lock; обновляйте geoip-country при регулярном обновлении зависимостей, чтобы сохранять актуальность GeoIP. Нельзя использовать адрес точки Railway Edge как страну пользователя: https://docs.railway.com/networking/edge-networking.

Приложение доверяет одному обратному прокси (`trust proxy=1`), как и до изменения. Инфраструктура должна перезаписывать/дополнять X-Forwarded-For реальным адресом клиента. CF-IPCountry, произвольные country-заголовки, параметры URL и язык браузера не используются. Если страна неизвестна (включая localhost), не выдумывается запрет; решение самого видеопровайдера остаётся действующим. VPN определяется по IP соединения, а не физическому местоположению.

Миграция 026 создаёт таблицы kodik_geo и kodik_geo_state. Фоновый процесс в startWorker сразу после запуска и далее раз в сутки полностью обходит /list с types=anime,anime-serial и limit=100. Ключ только в POST body. Собирается пересечение blocked_countries всех озвучек каждого точного Shikimori ID, в том числе между страницами. Если хотя бы одна озвучка не запрещена в стране, тайтл остаётся в каталоге. Все страны, озвучки и исходные данные Kodik не изменяются.

Снимок ограничений публикуется одной транзакцией только после полного успешного обхода. При ошибке остаётся прежний снимок, повтор через 15 минут. Lease защищает от параллельных процессов. Первая фильтрация появится после завершения первого обхода; пустая новая таблица не означает отсутствия ограничений у провайдера. При WORKER_ENABLED=false и отсутствии отдельного worker индекс не обновляется. Нужен уже используемый KODIK_API_TOKEN в процессе, запускающем worker.

Серверный requestAnimeAccess применяет географический фильтр к SELECT/WITH по anime: каталог, поиск, главная, связанные сезоны, страницы, история и player/offline API. Обычные пользователи и гости не получают скрытый тайтл по прямому URL. Для admin/moderator фильтр полностью отключён. В translations и при открытии Kodik отбираются разрешённые в стране озвучки без изменения общего кеша источника. В комнатах запрет отдельному зрителю не закрывает комнату для всех.

Sitemap сохраняется глобальным и одинаковым для посетителей разных стран, чтобы не создавать разные индексы URL. Сама страница соблюдает региональную видимость. Общего HTML-кеша между странами нет (динамические ответы no-store).

Это правило видимости YORU. Оно не отменяет проверку страны внутри Kodik и не разблокирует видео сотрудникам. Уже скачанные офлайн-фрагменты не удаляются удалённо.

Проверка на 2026-10-29: реальный API, 338 страниц / 33 774 материала; пересечение всех озвучек выявило 5 тайтлов с непустым списком стран. Обход выполнен с адаптером записи только в память, рабочая БД не изменялась. Тесты покрывают разные страны, роли, подложные заголовки, прямые API, смешанные озвучки, кеши и неполный обход.
