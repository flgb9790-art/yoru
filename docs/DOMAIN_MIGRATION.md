# Переход на yoru.one

Основной адрес: https://yoru.one. BASE_URL используется Telegram OIDC, письмами, плеерами и абсолютными ссылками. Для production заданы:

- BASE_URL=https://yoru.one
- LEGACY_SITE_ORIGINS=https://web-production-6bc5ed.up.railway.app
- SITE_REDIRECT=true

Старые браузерные ссылки получают постоянный 301 на новый адрес с сохранением пути и параметров. API, POST, технические проверки, файлы, callback Telegram, старая офлайн-библиотека и YORUAndroid остаются доступны на прежнем домене. Это позволяет обновлять установленные приложения постепенно. Назначение редиректа берётся только из BASE_URL, никогда из входящих заголовков.

В BotFather должны оставаться разрешены оба origin и оба /auth/telegram/callback. Старые callback сохраняются, чтобы завершать начатые входы и обслуживать APK 0.1.5. Код не переносит cookies между доменами. Аккаунт после повторного Telegram-входа определяется по прежнему telegram_id в той же базе.

Android 0.1.6 (versionCode 7) использует https://yoru.one и подписывается прежним ключом. Устанавливать поверх предыдущей версии, не удаляя приложение. Firebase-конфигурация и ключ подписи не меняются.

На новом домене нужно войти заново. Настройки браузера, PWA и Cache Storage привязаны к origin: тема и скачанные серии не переносятся автоматически. Старая библиотека остаётся доступна по https://web-production-6bc5ed.up.railway.app/offline/library в прежнем браузере. Для нового PWA добавить yoru.one на главный экран; необходимые серии скачать на новом домене заново.

Проверка после развёртывания: /health, /catalog, /apps, /offline/library, canonical, старые ссылки, OAuth redirect_uri, доступность обоих плееров, загрузка APK. Полный вход требует участия пользователя; автоматическая проверка ограничивается началом OIDC и корректностью адресов/состояния.

Откат: SITE_REDIRECT=false, BASE_URL=https://web-production-6bc5ed.up.railway.app, оставить LEGACY_SITE_ORIGINS с обоими разрешёнными HTTPS origin. Старые cookie/база не удаляются. Не удалять домен или сертификат для отката приложения.
