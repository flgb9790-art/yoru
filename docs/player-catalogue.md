# Видимость аниме с доступным плеером

Публичные страницы показывают тайтл, если хотя бы один источник подтвердил материал по точному Shikimori ID. Название, жанр, тип ONA/special и предполагаемое фанатское происхождение не используются как причина скрытия.

Миграция `027_player_catalogue.sql` добавляет общий индекс источников. Kodik заполняет его в существующем полном обходе географических ограничений: требуется проверенная ссылка iframe, а для сериала — доступные серии. AniLiberty использует существующий постраничный обход с деталями релизов: требуются разрешённый источник и хотя бы один действительный HLS-поток. Медиафайлы для такого обхода не скачиваются. Отдельный второй планировщик не добавлен.

Kodik публикует географию и наличие материалов в одной транзакции после последней страницы. AniLiberty собирает промежуточный список, проверяет последовательность страниц текущего цикла и публикует его только целиком. Ошибка API или перезапуск посреди цикла не превращают оставшиеся страницы в полный каталог. Пустой непроверенный индекс Kodik не заменяет прежний. Источники обновляются раз в сутки по прежним расписаниям; новые подтверждённые источники из свежего кэша/ленты могут появиться раньше.

После первой установки оба полных обхода запускаются заново. До завершения обоих первого снимка отсутствие информации не считается отсутствием плеера: это защищает каталог от массового скрытия при временном сбое API. После завершения снимков отсутствие в обоих источниках скрывает тайтл в каталоге, поиске, связанных списках, личных списках, публичной странице, API и sitemap. Админка и модерация сохраняют доступ к исходной записи. Тайтлы, библиотека, история, оценки и комментарии не удаляются. Появление плеера автоматически возвращает тайтл в публичную выдачу после подтверждения источника.

## Проверка 30 октября 2026

Полные каталоги источников сопоставлены с 9 325 тайтлами рабочей БД в режиме только чтения. У 6 693 найден хотя бы один источник, у 2 632 — ни одного. «Ложные гадания» (`Kyokou Uranai`, Shikimori 42562) отсутствуют в обоих источниках; отдельные проверки публичного Kodik и поиска AniLiberty также вернули отсутствие плеера. Основные сезоны «Ложных выводов» — другие тайтлы.

Локальный полный отчёт: `backups/player-catalogue-audit-2026-10-30.json`. Он содержит публичные идентификаторы и список тайтлов, без ключей API и пользовательских данных. SQL видимости дополнительно выполнен на настоящей PostgreSQL в read-only транзакции с индексами из отчёта через CTE: 6 693 результата. В рабочей БД ничего не менялось. Для включения фильтра необходимы деплой и завершение первых полных обходов.
