# Kodik: интеграция YORU

Личный ключ задаётся только на сервере как `KODIK_API_TOKEN`. Он не возвращается браузеру и не добавляется в URL запросов. Каталог вызывается POST на `https://kodik-api.com/search`; на 2026-10-29 проверен реальный ответ для Shikimori 52991: 33 перевода по 28 серий.

## Озвучки

`/api/player/:id/translations` возвращает только нормализованные варианты по точному Shikimori ID: id, название, тип, проверенную ссылку Kodik и доступные серии. Нет результатов чужих тайтлов, произвольных хостов или закрытых эпизодов. При отсутствии API-ключа/ошибке списка обычное публичное встраивание сохраняется.

Над плеером доступен выбор озвучки и субтитров сеткой кнопок с выбранным состоянием и клавиатурным управлением; видимого выпадающего списка нет. После успешного получения списка внутренний выбор отключается `translations=false`; `auto_translation=false` удерживает выбранный вариант. При переключении сохраняется серия и позиция. При недоступном каталоге внутренний выбор остаётся доступным.

## Команды и события

Команды: `{key:'kodik_player_api',value:{method,...параметры}}`. Получатель строго `https://kodikplayer.com`. Входящие события проверяются по `event.origin`, `event.source`, размеру строки и типам данных. Обработчики удаляются при уходе со страницы.

Настольная кнопка PiP после запуска: `enter_pip` / `exit_pip`; состояние обновляется только событиями `kodik_player_enter_pip` / `kodik_player_exit_pip`. Кнопка скрыта на телефонах и при отсутствии поддержки PiP браузером. Реальное системное окно требует пользовательского клика.

Комнаты используют `play`, `pause`, `seek`, `change_episode` с `without_reload`, `volume`, `mute`, `unmute`, `speed`. Начальный запуск — после загрузки iframe и пользовательского клика. `hide_selectors=true`, `hide_resume_button=true` и `auto_translation=false` предотвращают независимый выбор серий/озвучек в UI iframe. Сервер принимает изменения только от действующего ведущего; звук остаётся личным. Зрительский seek/pause внутри iframe не меняет общее состояние и корректируется синхронизацией.

Миграция 025 добавляет provider и season; старые комнаты получают aniliberty и сезон 1. Комната Kodik привязана к выбранному переводу и первому доступному сезону; внутри комнаты выбираются серии этого сезона. Ограничения источника повторно проверяются, отозванный доступ закрывает комнату. XP начисляется существующим механизмом завершения серии один раз.

## Опенинг и эндинг

В редакторе аниме можно задать точные интервалы Kodik по строкам:

```
1.1: [opening]12-90,[ending]24:12-26:15
1.2: [opening]0-89
```

Формат ключа — сезон.серия. Метки: opening, ending, intro, credits. Отрицательные/обратные/пересекающиеся интервалы не допускаются. Правила сохраняются как `metadata.kodik_skip_rules`, защищаются от импорта и передаются в `skip_button` только соответствующей серии. При смене серии старый параметр удаляется/заменяется; в комнатах смена URL с другими таймингами может потребовать повторного подключения плеера. Универсальные или автоматически угаданные интервалы не используются. Отсутствие ручного правила не отключает штатные возможности Kodik.

## Скачивание: изолированный пробник

Для проверки подключён kodikwrapper 3.1.0 (VideoLinks); версия зафиксирована lock-файлом. Это отдельное получение ссылок из плеера, а не документированный каталожный API Kodik. Эндпоинты источника могут меняться.

Пробник доступен только администратору и только для Shikimori 61987 («Монолог фармацевта 3»), первой серии выбранной озвучки. API /api/offline/kodik-trial/:id проверяет права, публичность/блокировку тайтла, соответствие Shikimori/озвучки/сезона, ограничения источника и вновь проверяет блокировку перед ответом. Озвучки с региональными ограничениями не поддерживаются пробником. Ключ остаётся на сервере; произвольные ссылки от клиента не принимаются.

Ссылки извлекаются только у kodikplayer.com: максимум 6 внутренних запросов, явный timeout, редиректы запрещены. Возвращаются только HLS на проверенном CDN pN.solodcdn.com. Медиаданные скачиваются браузером напрямую с CORS и без cookies; сервер не проксирует серии. Нет попыток обработки DRM/SAMPLE-AES. Ограничения качества/размера и приостановка/повтор из прежней библиотеки сохранены.

В офлайн-очереди и метаданных появился provider. Ключи Kodik отделены от AniLiberty, старые записи и VIDEO_PREFIX не менялись; shell обновлён до v8. Bootstrap обновляет старый Service Worker до импорта модулей; переход v7 → v8 и повторная офлайн-загрузка страницы проверены в Chromium, видео не удаляются. Учитывается реальный сезон источника (у этого тайтла — сезон 3). Поддержаны 360/480/720/1080 при фактическом наличии; в проверенной серии доступны 360/480/720.

Реальный тест 2026-10-29: «Монолог фармацевта 3», серия 1, сезон источника 3, «РуАниме / DEEP», 480p. Сохранены 241 фрагмент, 114575096 байт (~109,3 МиБ). Chromium: сеть отключена, воспроизведение и seek на 600 секунд проходят без внешних запросов; после закрытия и повторного запуска браузера офлайн-страница и сохранённая позиция работают. Медиапоток не подменялся тестовыми фрагментами. iPhone/PWA пока не проверены на устройстве. Срок действия подписанных онлайн-ссылок отдельно не измерялся.

Для теста после публикации: администратор открывает тайтл, выбирает Kodik и озвучку кнопкой, затем «Скачать» и первую серию. Сохраняется библиотека браузера, обычный MP4 в папке загрузок не создаётся. Расширять пробник на весь каталог до проверки на телефоне не стали.

## Проверки

Unit/HTTP: каталог, права/CSRF комнат, отозванный доступ, безопасные команды/события, PiP, переключение озвучки, тайминги. Chromium с двумя сессиями и тестовым iframe, воспроизводящим документированный протокол: создание комнаты, пауза/смена серии, локальный звук, внешние озвучки и PiP-события. Управление iframe проверялось на стенде протокола, настоящее системное окно PiP этим тестом не проверено. Реальные скачивание, офлайн-воспроизведение и перезапуск браузера проверены отдельно на серии Kodik, как описано выше. Production БД не изменялась.

Общие правила postMessage: https://developer.mozilla.org/ru/docs/Web/API/Window/postMessage . Контракт Kodik взят из присланных пользователем скриншотов закрытой документации.

### Расширение загрузок (2026-10-29)
Пробник расширен на публичные тайтлы с доступной озвучкой Kodik. `/api/offline/kodik/:id?release=ID` возвращает список серий первого доступного сезона озвучки; с `episode=N&season=S` подготавливает поток конкретной серии. Извлечение ленивое, видео по-прежнему идёт напрямую с CDN. В меню предлагается 360/480/720p; фактическое наличие качества проверяется перед загрузкой, отдельная серия может завершиться понятной ошибкой. Региональные ограничения не обходятся. AniLiberty работает прежним путём. Офлайн shell v9 сохраняет прежний префикс видеокешей. На телефоне озвучки выбираются select, на ПК карточками.

Iframe сериалов ограничен only_season=true: выбор серий сохраняется, переход на другие сезоны осуществляется страницами сайта. При смене озвучки используется её сезон из каталога. Комнаты также закреплены за своим сезоном.

### Офлайн на ПК
Офлайн-библиотека и кнопка скачивания доступны также в браузере ноутбука/ПК для обоих источников. Вход через меню «Ещё» → «Загрузки» или окно аккаунта. От 1000 px список тайтлов и серий расположен в двух колонках. Страница /offline/library работает без сети после подготовки; хранение привязано к браузеру и домену, не является экспортом MP4. Shell v10 обновляется с сохранением кешей видео.
