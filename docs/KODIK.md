# Kodik: интеграция YORU

Личный ключ задаётся только на сервере как `KODIK_API_TOKEN`. Он не возвращается браузеру и не добавляется в URL запросов. Каталог вызывается POST на `https://kodik-api.com/search`; на 2026-10-29 проверен реальный ответ для Shikimori 52991: 33 перевода по 28 серий.

## Озвучки

`/api/player/:id/translations` возвращает только нормализованные варианты по точному Shikimori ID: id, название, тип, проверенную ссылку Kodik и доступные серии. Нет результатов чужих тайтлов, произвольных хостов или закрытых эпизодов. При отсутствии API-ключа/ошибке списка обычное публичное встраивание сохраняется.

Над плеером доступен выбор озвучки и субтитров. После успешного получения списка внутренний выбор отключается `translations=false`; `auto_translation=false` удерживает выбранный вариант. При переключении сохраняется серия и позиция. При недоступном каталоге внутренний выбор остаётся доступным.

## Команды и события

Команды: `{key:'kodik_player_api',value:{method,...параметры}}`. Получатель строго `https://kodikplayer.com`. Входящие события проверяются по `event.origin`, `event.source`, размеру строки и типам данных. Обработчики удаляются при уходе со страницы.

Настольная кнопка PiP после запуска: `enter_pip` / `exit_pip`; состояние обновляется только событиями `kodik_player_enter_pip` / `kodik_player_exit_pip`. Кнопка скрыта на телефонах и при отсутствии поддержки PiP браузером. Реальное системное окно требует пользовательского клика.

Комнаты используют `play`, `pause`, `seek`, `change_episode` с `without_reload`, `volume`, `mute`, `unmute`, `speed`. Начальный запуск — после загрузки iframe и пользовательского клика. `hide_selectors=true`, `hide_resume_button=true` и `auto_translation=false` предотвращают независимый выбор серий/озвучек в UI iframe. Сервер принимает изменения только от действующего ведущего; звук остаётся личным. Зрительский seek/pause внутри iframe не меняет общее состояние и корректируется синхронизацией.

Миграция 025 добавляет provider и season; старые комнаты получают aniliberty и сезон 1. Комната Kodik привязана к выбранному переводу и первому доступному сезону; внутри комнаты выбираются серии этого сезона. Ограничения источника повторно проверяются, отозванный доступ закрывает комнату. XP начисляется существующим механизмом завершения серии один раз.

## Опенинг и эндинг

В редакторе аниме можно задать точные интервалы Kodik по строкам:

```
1.1: [opening]12-90,[ending]24:12-26:15
1.2: [opening]0-89
```

Формат ключа — сезон.серия. Метки: opening, ending, intro, credits. Отрицательные/обратные/пересекающиеся интервалы не допускаются. Правила сохраняются как `metadata.kodik_skip_rules`, защищаются от импорта и передаются в `skip_button` только соответствующей серии. При смене серии старый параметр удаляется/заменяется; в комнатах смена URL с другими таймингами может потребовать повторного подключения плеера. Универсальные или автоматически угаданные интервалы не используются. Отсутствие ручного правила не отключает штатные возможности Kodik.

## Скачивание

Не подключено. Документированные `link` / `seasons.episodes` — URL iframe, не MP4/HLS. `postMessage` не открывает доступ к видеофайлам. Для расширения офлайн-библиотеки нужна документация/выданный доступ к прямым видеопотокам и возможность их чтения браузером (CORS). Внутренние механизмы выдачи потоков не извлекались.

## Проверки

Unit/HTTP: каталог, права/CSRF комнат, отозванный доступ, безопасные команды/события, PiP, переключение озвучки, тайминги. Chromium с двумя сессиями и тестовым iframe, воспроизводящим документированный протокол: создание комнаты, пауза/смена серии, локальный звук, внешние озвучки и PiP-события. Это не проверка воспроизведения реального CDN или настоящего системного окна PiP. Реальный каталог проверен отдельно без изменения production БД.

Общие правила postMessage: https://developer.mozilla.org/ru/docs/Web/API/Window/postMessage . Контракт Kodik взят из присланных пользователем скриншотов закрытой документации.
