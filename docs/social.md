# Комментарии, сообщения и удаление аниме

Миграция `012_social.sql` применяется штатным запуском миграций. Существующие комментарии остаются корневыми ветками.

В обсуждении доступны ответы, лайки/дизлайки, спойлеры и удаление своего комментария. Администратор и модератор тоже могут удалять комментарии. После удаления текст стирается, но ответы остаются под отметкой «Комментарий удалён». Один пользователь имеет одну реакцию на комментарий; повторное нажатие снимает её. Свои комментарии оценивать нельзя. Корневые ветки показываются по 20, ответы — по 20 в открытой ветке; в общем списке видны первые три ответа.

Сообщения открываются через конверт в шапке или `/messages`. После миграции `013_messenger.sql` это единое окно мессенджера: список диалогов/контактов и живой поиск слева, переписка справа. На телефоне список и выбранный чат отображаются по очереди, есть кнопка назад. Переходы между чатами сохраняют окно и черновики текста до выхода из раздела. Черновики не записываются в браузерное хранилище.

Новый диалог — поиск по имени пользователя (также поддерживается точное совпадение ID). «В контакты» сохраняет собеседника в личном списке `user_contacts`: без заявки и без взаимного добавления, как контакты в мессенджере. Кнопка повторного нажатия убирает контакт. Enter отправляет, Shift+Enter переносит строку. На телефоне можно отправлять кнопкой. Скрепка открывает поиск аниме для прикрепления. На странице аниме также есть «Поделиться аниме»: выберите получателя, дополните текстом и отправьте. Карточку из сообщения можно переслать другому пользователю.

Переписка доступна только её участникам; администратору отдельного просмотра чужих сообщений нет. По 30 сообщений на страницу, по 20 диалогов/контактов/результатов поиска. Более ранняя история открывается внутри чата. Повтор запроса с тем же `request_id` не дублирует сообщение. Индекс списка получает последние сообщения по собеседникам, а не загружает всю переписку.

Колокольчик показывает новые серии и ответы на комментарии. Личные сообщения отмечаются отдельно у конверта и в списке диалогов. Миграция `014_message_badges.sql` убирает старые записи о сообщениях из `social_notifications`, сохраняя переписки. Новые сообщения таких записей не создают; чтение общих уведомлений не читает личную переписку.

Пока вкладка открыта и видима, уведомления и список диалогов обновляются каждые пять секунд, текущая переписка — каждые 1,5 секунды. На скрытой вкладке опрос приостановлен. «В сети» означает активность в окне чата за последние 15 секунд. Индикатор «печатает» виден только адресату и сам истекает через 6 секунд; содержимое черновика на сервер не отправляется. Внешних push-уведомлений при закрытом сайте нет. Прочтение отмечает только входящие сообщения от выбранного собеседника, когда пользователь находится внизу актуальной переписки. Формы защищены общей CSRF-проверкой; отправка сообщений ограничена 120 в минуту с одного IP.

В мобильном чате размер текста полей не меньше 16px, без запрета ручного масштабирования. При уменьшении visualViewport под клавиатуру шапка сайта временно убирается, высота чата и поиска вложений подстраивается под доступное место; при закрытии клавиатуры шапка возвращается.

Удаление доступно администратору внизу формы редактирования аниме. Отдельная страница требует подтверждающий флажок. Удаляются тайтл и связанные записи каталога, библиотек, истории и обсуждения; снимок сохраняется в `deleted_anime.snapshot`, действие — в журнале `audit`. Уже отправленные сообщения сохраняют название аниме с пометкой о недоступности. Shikimori ID исключается из повторного импорта. Импорт и удаление используют общую блокировку по этому ID. Интерфейса восстановления архива пока нет.

Локальная проверка: `node --test --test-concurrency=1 test/social.test.js`. Полный набор: `npm test`.
