# Техническое SEO YORU

Проверено 28 октября 2026 года. Основной адрес: https://yoru.one.

## Настройка

- SSR: уникальные title/description, canonical, robots, Open Graph, JSON-LD WebSite/WebPage и Movie/TVSeries/CreativeWork; видимые хлебные крошки с BreadcrumbList. Разметка использует данные произведения; оценки других сайтов не выдаются за собственные отзывы.
- robots.txt разрешает публичные страницы и ресурсы отрисовки; исключает технические endpoints, авторизацию, администрирование, APK и локальную библиотеку. Доступ к закрытым данным по-прежнему защищён авторизацией.
- /sitemap.xml содержит индекс. /sitemaps/pages.xml перечисляет основные разделы и существующие публичные жанры/форматы/страны. /sitemaps/anime-N.xml содержит по 1000 открытых тайтлов. Данные формируются из базы. lastmod не выдумывается на основании технической синхронизации.
- В карте нет заблокированных, анонсов без серий, staff-only тайтлов, закрытых жанров, личных страниц или поисковых комбинаций. Правило одинаково для гостей и администраторов.
- Основной каталог и одиночные жанр/страна/формат индексируются. Поиск, сортировка, сложные фильтры, фильтр плеера, личные и служебные разделы получают noindex.
- Параметры источника, серии, обсуждения и рекламных меток не создают canonical-дублей страницы аниме. Пагинация каталога сохраняет отдельные canonical. Пустые результаты не индексируются, недоступные номера страниц возвращают 404.
- Старый домен перенаправляется постоянным 301 с сохранением пути и параметров; совместимость старого Android, callback, API и офлайн-библиотеки сохранена. Нормализуются регистр и завершающий слеш основных публичных маршрутов.
- AJAX/Back обновляют метаданные и JSON-LD. CSP не ослаблена через unsafe-inline; используется nonce. На главной один H1; заголовки жанров соответствуют содержимому, оригинальные названия видны на страницах аниме. Размеры постеров заданы, главное изображение получает приоритет.

## Результат проверки опубликованной версии

- 11 XML-файлов, 9419 URL, включая 9324 открытых тайтла. Дублей нет, XML разобран парсером. Числа меняются с наполнением каталога.
- robots и sitemap отвечают 200; дальняя пустая пагинация и неизвестные URL — 404 с noindex. Поиск/вход не индексируются, публичные страницы аниме имеют index/canonical/description/schema.
- Проверены SSR без JavaScript, AJAX/Back и отсутствие CSP/JS-ошибок. Полный прогон: 235/235 тестов.
- Search Console ещё не подключена, sitemap в Google от имени владельца не отправлялся.

## Следующий шаг: Search Console

1. Добавить ресурс типа «Домен»: yoru.one без протокола и пути.
2. Получить TXT google-site-verification=... и добавить предоставленное значение в DNS. Существующую _railway-verify сохранить.
3. Подтвердить владение и отправить https://yoru.one/sitemap.xml.
4. В «Проверке URL» проверить главную, каталог и несколько аниме: доступность, canonical, отрисованный текст и отсутствие noindex.
5. Следить за 5xx, soft 404, неожиданными canonical, обнаруженными/проиндексированными страницами и Core Web Vitals. Ожидаемые noindex личных разделов и поиска не являются неисправностью.

Для URL-prefix ресурса дополнительно поддержан GOOGLE_SITE_VERIFICATION — только токен HTML-метатега; Domain-ресурс подтверждается DNS. Техническая доступность не гарантирует автоматического включения каждой страницы в индекс: результат проверяется после обхода Google.

## Видео

Страницы аниме доступны роботу, но видео загружается действием пользователя и поступает от внешних источников. Полноценная видеоиндексация требует отдельной работы: плеер без обязательного клика, стабильные thumbnails, проверяемые данные конкретного выпуска. VideoObject и video sitemap с выдуманными uploadDate/contentUrl не добавлялись.
