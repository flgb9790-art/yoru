# YORU

Ранняя рабочая версия аниме-каталога на Node.js 24, Express и PostgreSQL.

## Запуск

1. `npm ci`
2. Скопировать `.env.example` в `.env`, указать `DATABASE_URL`.
3. `npm start` — миграции выполняются при старте. Открыть `http://localhost:3000`.
4. `npm test` — изолированные интеграционные тесты через pg-mem.

На Railway создать PostgreSQL и сервис web, задать `DATABASE_URL=${{Postgres.DATABASE_URL}}`, `NODE_ENV=production`. Dockerfile устанавливает только рабочие зависимости. `/health` проверяет соединение с БД. Секреты никогда не коммитить.

## Первое наполнение и администратор

`node --env-file-if-exists=.env scripts/import.js 52991` импортирует настоящие данные, кадры, участников и связанные части из Shikimori. Запросы ограничены интервалом 1,2 секунды; не выполнять параллельно несколько процессов массового импорта.

Зарегистрировать обычный аккаунт через сайт. Затем владелец проекта выполняет `node --env-file-if-exists=.env scripts/promote-admin.js email@example.com`. Публичного маршрута повышения роли нет. Подтверждение почты не подменяется этим действием.

## Что уже работает

- PostgreSQL, сохранение пользователей и сеансов, хеширование паролей, CSRF-защита и ограничение попыток входа.
- Каталог, поиск, пересечение жанров, фильтры, сортировка, пагинация.
- Страницы аниме, реальные кадры, сведения об авторах и студиях, связанные части.
- Админка с ручным редактированием, очередь импорта по ID, защита ручных полей, блокировки и журнал действий.
- Библиотека и серверные маршруты истории; история пока не заполняется без подключённого плеера.
- Регистрация и вход по почте. Комментарии требуют подтверждённую почту, поэтому до подключения почты недоступны обычным новым аккаунтам.

## Ещё не завершено

- Дизайн перенесён частично; оригинал согласованного интерактивного макета остаётся эталоном.
- Telegram-вход, письма подтверждения и восстановления пароля.
- Автоматическое обновление всего каталога по расписанию, определение страны для китайских тайтлов.
- Видеоисточник, серии и озвучки, история фактических просмотров. Обновление каталога не выдаётся за появление перевода.
- Аватары и обложки, полноценная модерация, рейтинги пользователей, подборки.
- Резервное копирование и проверка восстановления перед публичным запуском.

`railway.json` поддерживается Railway до 2026-12-01 по сообщению CLI. До этого срока нужно мигрировать настройки в актуальный IaC, не полагаться на устаревший формат.

Текущая версия рассчитана на один web-процесс с встроенным обработчиком заданий. Для масштабирования вынести обработчик и глобальное ограничение запросов в отдельный сервис.
