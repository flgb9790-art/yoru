# YORU

Рабочий каталог аниме: Node.js 24, Express, PostgreSQL, Telegram OIDC и Railway.

## Запуск

1. `npm ci`
2. Скопировать `.env.example` в `.env`, указать PostgreSQL `DATABASE_URL`.
3. `npm start` — миграции при старте, порт из `PORT` (по умолчанию 3000).
4. `npm test` — изолированные интеграционные тесты pg-mem.

На Railway: PostgreSQL и web, `DATABASE_URL=${{Postgres.DATABASE_URL}}`, `NODE_ENV=production`, `AUTH_MODE=telegram`, `AUTO_SYNC=true`, `BASE_URL` с публичным HTTPS адресом. Dockerfile устанавливает рабочие зависимости; `/health` проверяет БД. Секреты исключены из Git и Docker.

## Telegram

В BotFather включить OpenID Connect Login, Redirect URI: `BASE_URL/auth/telegram/callback`, Trusted Origin: `BASE_URL`. Указать `TELEGRAM_CLIENT_ID` и `TELEGRAM_CLIENT_SECRET` в Railway, RS256. Сервер проверяет state, PKCE, nonce, issuer, audience и подпись JWT. Вход по почте отключён в режиме Telegram; код SMTP оставлен для следующего этапа.

## Каталог и кабинет

- Поиск, пересечение нескольких жанров, страна, год, формат, статус, сортировка и пагинация.
- Главная: карусель до 14 тайтлов (7 видимых на ПК), 20 обновлений по 5 в ряд, 10 китайских тайтлов. Каталог и расписание — 24, 6 в ряд на ПК.
- Страница аниме: данные Shikimori, оценки сайта, кадры, фон из кадра, таймер оригинального эфира, связанные части, порядок выхода частей и карусель похожих историй по общим жанрам.
- Кабинет: имя, аватар и обложка, статистика, история, библиотека со статусами и удалением. История хранит уникальную запись для каждой серии, полная история по 8 записей.
- Изображения PNG/JPEG/WebP до 3 МБ хранятся в PostgreSQL, переживают развёртывания. Проверка сигнатур; серверное преобразование изображений пока не реализовано.
- Комментарии со спойлерами, оценки от 1 до 10, роли user/moderator/admin. Модератор управляет комментариями; администратор — каталогом и ролями. Снять собственную роль администратора через интерфейс нельзя.

## Администрирование и синхронизация

- Каталог и чёрный список: поиск и страницы по 20 аниме; блокировка запрещает просмотр, сохраняя страницу.
- Полная ручная форма; заполнение по Shikimori ID перед сохранением; запрет дубликатов ID.
- Очередь импорта, пакетное наполнение по 20 тайтлов, повтор неудачного задания. Ошибки автоматически повторяются до 3 попыток.
- Изменённые ручные поля можно защитить. Защита автора не замораживает число вышедших серий и другие импортируемые сведения.
- При AUTO_SYNC раз в час в очередь ставятся до 20 записей, синхронизированных более 6 часов назад. Раз в сутки обнаруживаются до 20 последних онгоингов и до 20 завершённых релизов Shikimori; это ограниченное обнаружение, не полный обход всего источника.
- Shikimori REST используется для сведений, участников и кадров; GraphQL — для актуального постера, nextEpisodeAt и хронологии. Интервал запросов 1,2 секунды внутри одного процесса. Не запускать несколько массовых импортёров параллельно.
- Страна в Shikimori не дана отдельным полем. Китайские тайтлы выделяются вручную, страна защищается от перезаписи; общее определение страны по всей базе ещё требует отдельного источника.
- Даты эфира показаны в МСК. Порядок выхода частей не выдаётся за рекомендованный сюжетный порядок.

## Плеер Kodik

Плеер подключается через публичный метод get-player, который используется собственным скриптом Kodik: https://kodik-add.com/add-players.min.js . Отдельный личный API-ключ для этого метода не нужен: публичная конфигурация считывается сервером и кэшируется на 6 часов. Чужие приватные ключи не используются. Если формат публичной конфигурации изменится, интеграция вернёт понятную ошибку.

- Поиск строго по Shikimori ID, с настоящим адресом сайта; ответ allowed учитывается.
- Ссылка на плеер кэшируется на 30 минут, отсутствие — на 5 минут. Кэш привязан к BASE_URL. Разрешён только HTTPS iframe kodikplayer.com; данные и медиа не проксируются.
- Загрузка по нажатию «Смотреть» или «Открыть плеер». Выбор серии, сезона и озвучки — внутри родного плеера.
- История сохраняется только после событий воспроизведения, не при загрузке iframe. Принимаются сообщения только от окна текущего плеера с точным origin. Прогресс отправляется не чаще раза в 15 секунд, дополнительно при паузе и уходе со страницы.
- Сезон входит в уникальный ключ серии. Завершённый просмотр не отменяется при повторном начале. При открытии продолжается последняя незавершённая серия с сохранённой позиции, с отступом 5 секунд. Выбор прежней озвучки автоматически не гарантируется.
- Административная блокировка проверяется до выдачи ссылки и после обращения к провайдеру. Открытый плеер проверяет блокировку раз в минуту и при возвращении во вкладку.
- Региональные и прочие ограничения Kodik сохраняются. Ошибки внутри iframe показывает провайдер. В проверочном браузере настоящий iframe показал запрет по стране; реальное воспроизведение видео в этой среде не подтверждено. Сохранение и возобновление проверены управляемыми событиями на тестовом стенде и интеграционными тестами.

Полный API /search и /list требует отдельной авторизации. Публичное встраивание не предоставляет полноценную ленту новых переведённых серий. Блок на главной всё ещё явно показывает обновления каталога. Для настоящей ленты релизов понадобится доступ к каталожному API или другой разрешённый источник дат. Почта и уникальные переписанные описания отложены владельцем.

Перед публичным запуском: настроить резервные копии PostgreSQL и проверить восстановление; отдельно проверить интеграцию видеоисточника. Версия рассчитана на один web-процесс со встроенным обработчиком заданий. Для масштабирования нужны отдельный worker и общее ограничение запросов.

Railway CLI предупреждает: railway.json поддерживается до 2026-12-01. До этого срока перенести настройки в актуальный IaC.

## Второй источник — AniLiberty

На странице есть выбор Kodik / AniLiberty. AniLiberty использует публичный API api.anilibria.app/api/v1: поиск по оригинальному и русскому названию с обязательным точным совпадением Shikimori ID, затем получение релиза. При is_blocked_by_geo / is_blocked_by_copyrights, а также отсутствии явного разрешения просмотр не предлагается. Кэш — 10 минут для найденных серий, 3 минуты для отсутствующих. Подмена страны и модификация параметров видео не выполняются.

HLS воспроизводится непосредственно с CDN *.libria.fun: нативно в поддерживающих браузерах или через локально раздаваемую закреплённую зависимость hls.js. Медиа через Railway не проксируется. Выбор серии, 480/720/1080p (если источник предоставляет), общая история и возобновление. При смене качества позиция сохраняется. Смена источника требует явного выбора. Каталог AniLiberty покрывает только собственные релизы; отсутствие у него тайтла не считается ошибкой сайта. Дробные номера спецвыпусков пока не поддерживаются.

На локальном стенде проверено настоящее воспроизведение трёх тайтлов (Shikimori 52991, 51009, 57612), смена серии и качества, реальные события истории и мобильная вёрстка. Кадры декодировались в 1280 px, время шло. Утверждение выше о непроверенном видео относится к прежнему тесту Kodik; AniLiberty проверен отдельно. Полная лента новых переводов на главной ещё не реализована.

Публичная проверка на Railway подтвердила воспроизведение этих трёх тайтлов, реальные события истории, смену серии/качества, возобновление воспроизведения после 30-й секунды и мобильный вид. Механизм блокировки HTML5 видео дополнительно проверен управляемым ответом статуса. Всего 22 теста проходят.
